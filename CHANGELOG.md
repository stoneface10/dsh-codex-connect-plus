# Changelog

All notable changes to this project are documented here.

## Unreleased

## 0.1.0-alpha.3 - 2026-08-16

### Changed

- Defaulted subscription-backed Codex model requests to zero automatic retries, preventing one transient failure from silently replaying the complete request up to two additional times.
- Added a live `modelMaxRetries` setting with an explicit 0–2 range; zero remains the recommended quota-conserving choice.
- Kept `gpt-image-2` generation and editing non-retrying because a timed-out upstream request may already have completed and consumed quota.

### Documentation

- Documented the retry/quota tradeoff and the distinction between provider-reported subscription windows and DSH token/cache accounting.

## 0.1.0-alpha.2 - 2026-08-16

### Fixed

- Removed Host-only `@deepseek-ai/dsh-attachment` and `@deepseek-ai/dsh-tools` imports from the browser bundle, fixing `client-modules: require(...) missed the module table` during Web GUI boot.
- Added a browser-bundle purity gate, simulated DSH module-table load, packed-import resolution checks, and committed-artifact drift checks so unsupported or stale runtime imports fail before release.
- Added CI coverage for both declared Node runtime lines: 22.19.0 and 24.
- Unified OAuth, search, and image provider-error redaction for Bearer/JWT credentials and structured token, authorization, code, `b64_json`, and image-data fields.
- Rejected linked/junction image-output parents and canonical paths outside the session cwd before writing generated bytes.
- Bounded image prompts and provider-returned image counts in addition to existing byte limits.
- Reported the exact package version in the Codex Images user agent.

### Documentation

- Clarified cross-platform credential-file permissions, exact error-redaction scope, unpublished API status, upstream-change risk, and service-term responsibility.

## 0.1.0-alpha.1 - 2026-08-16

### Features

- Combined ChatGPT/Codex OAuth, model routing, optional search, `view_image`, and `gpt-image-2` generation/editing in one DSH plugin.
- Added session-authorized generated-image previews and durable attachment replay.

### Security

- Added fixed-origin image requests, redirect rejection, bounded responses, strict base64 and image-signature validation, cancellation, timeout handling, credential-safe errors, atomic output allocation, and aggregate input limits.

### Documentation

- Added derivative provenance, third-party notices, security guidance, migration notes, and an upstream-aligned release process.

Initial community Alpha derived from `dsh-codex-connect` v0.1.0-alpha.4.5.
